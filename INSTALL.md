# Instalación - Chrome Tab Cleaner

Para probar esta extensión localmente:

1. Abrí Chrome y navegá a `chrome://extensions/`.
2. Activá el **"Modo de desarrollador"** (Developer mode) en la esquina superior derecha.
3. Hacé clic en **"Cargar no empaquetada"** (Load unpacked).
4. Seleccioná la carpeta: `~/Desktop/Oficina_Ranuk/chrome-tab-cleaner`.

**Cómo funciona:**
- El script revisa automáticamente cada 5 minutos.
- Cierra pestañas inactivas por más de 30 minutos.
- **Protege** sitios como Google, GitHub y Gmail.
- Podés forzar la limpieza haciendo clic en el icono de la extensión.
